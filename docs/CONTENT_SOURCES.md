# Content sources

- **Skills outline:** the public AZ-900 study guide on Microsoft Learn (skills measured as of 20 Jul 2026): Describe cloud concepts (25–30%), Describe Azure architecture and services (35–40%), Describe Azure management and governance (30–35%).
- **Learning paths:** the three AZ-900 learning paths and their 12 modules (links in `content/modules.json`). Notes in `content/topics.json` were written in our own words and checked against each module page in October 2026.
- **Questions:** all 194 practice questions in `content/questions.json` are written by us. We checked them against the wording of Microsoft's practice assessment with an automatic overlap scan (7-word sequences) and rewrote the five that came too close. Remaining overlaps are only public skills-outline headings.
- **Cards and analogies:** `content/cards-d*.json`, written by us. Each analogy states where it breaks. Kiswahili text was written with AI assistance and reviewed; corrections are welcome.
- **No Microsoft logos or trademarks** are used beyond naming the exam and the services, as needed to describe them.
